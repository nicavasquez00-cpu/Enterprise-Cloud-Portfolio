# Enterprise-Cloud-Portfolio

## Laboratory 1-5

This repository contains the requirements, configurations, scripts, documentation, and reflection for the Enterprise Cloud Laboratory activities.

## Requirements

### Requirement 1: Base Infrastructure & Architecture Design
Shows the base infrastructure setup and system architecture.

### Requirement 2: Infrastructure Integration (Deployment)
Shows the deployment and integration of the cloud infrastructure.

### Requirement 3: Security Configurations (Hardening)
Shows the security settings and hardening applied to the system.

### Requirement 4: Automation Scripts (Disaster Recovery/Ops)
Shows the automation script used for backup, recovery, and system operations.

### Requirement 5: Technical Documentation
Contains the technical documentation and supporting screenshots.

## Project Files

- `architecture-diagram.png` – Visual representation of the system architecture.
- `docker-compose.yml` – Defines and configures the Docker services.
- `automation-script.sh` – Automates backup and operational tasks.
- `operational-manual.md` – Provides instructions for operating the system.
- `final-reflection.md` – Summarizes the learning experience and project reflection.
